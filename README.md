# rokemodell

Webseite von rokemodell – Voll-GFK-Segelflugmodelle von Roland.

Reines HTML, CSS und JavaScript, ohne Build-Schritt und ohne externe Dienste.

## Struktur

```
index.html        Startseite (Bauplan, Über Roland, Modelle, Kontakt)
impressum.html    Impressum und Datenschutz
css/style.css     Gestaltung
js/main.js        Menü, Zeichen-Animation, E-Mail-Link
```

## Lokal ansehen

`index.html` einfach im Browser öffnen.

## Arbeitsweise

- `main` enthält immer den veröffentlichten Stand.
- Änderungen entstehen in eigenen Branches (`feature/...`, `fix/...`) und kommen per Pull Request nach `main`.

## Offene Punkte

- E-Mail-Adresse in `index.html` eintragen (`data-user` / `data-domain` am Kontakt-Knopf)
- Impressum und Datenschutz vervollständigen
- Beschreibungen und Daten zu Grob 109 und Speed Canard SC01 B ergänzen
- Fotos der Modelle
